# Tadicoba

**Satu ruang, dua perjalanan.** Platform belajar mandiri bahasa Jepang dan bahasa Inggris, dengan antarmuka bahasa Indonesia, materi harian, latihan, cerita bergambar, dan pendamping belajar **Nao**.

[Website](https://tadipuhan.github.io/Dailyactivity/) · [Repository](https://github.com/Tadipuhan/Dailyactivity)

Dokumentasi diperbarui **10 November 2026**, mengikuti HTML unduhan terbaru dengan dua cerita pada **Mode Berpetualang**. Dokumentasi ini tidak menyatakan bahwa versi tersebut sudah dipublikasikan ke GitHub Pages.

## Ringkasan

| Bagian | Fitur |
| --- | --- |
| Jepang | Materi 45 hari, dasar kana, kanji dan kotoba pilihan N5–N1, flashcard, cerita, serta latihan berbicara. |
| Inggris | A1–B1, masing-masing tujuh modul, alfabet, verbs, referensi tenses, kosakata, cerita, dan tutorial. |
| Mode Berpetualang | Dua cerita Nao, masing-masing 12 chapter; dialog, audio, furigana, dan paket 5–10 soal acak. |
| Cerita bergambar | Cerita Jepang, lima serial Nao, serta 15 cerita Inggris. |
| Print / PDF | Materi pilihan, kana, kanji, dan kosakata melalui dialog cetak browser. |
| Progres | Penyimpanan lokal di browser dan cadangan JSON melalui menu yang tersedia. |

Materi disusun untuk latihan mandiri. Label level merupakan cakupan belajar aplikasi, bukan sertifikasi atau hasil ujian resmi JLPT/CEFR.

## Mulai menggunakan

1. Buka halaman awal dan pilih **Bahasa Jepang** atau **Bahasa Inggris**.
2. Untuk Jepang, lanjutkan melalui intro Shōji menuju dashboard. Mulai dari **Dasar Jepang** jika belum mengenal hiragana dan katakana.
3. Untuk Inggris, ikuti **Tutorial Nao**, kemudian **Alfabet & membaca → Verbs → Day 1**.
4. Pelajari materi sebelum mengerjakan latihan. Gunakan cerita dan audio untuk pengulangan.
5. Gunakan **Ganti pelajaran** untuk kembali ke pemilih bahasa.
6. Ekspor cadangan sebelum berpindah perangkat, browser, atau alamat situs.

## Bahasa Jepang

- **Materi harian Day 1–45**, untuk penguatan dasar N5 dan persiapan N4, disertai soal serta pembahasan.
- **Dasar Jepang:** hiragana, katakana, contoh, bantuan membaca, latihan, audio, dan animasi goresan sesuai menu.
- **Kanji:** referensi pilihan N5–N1, arti Indonesia, bacaan, pencarian, pengelompokan, dan penanda belajar sesuai fitur yang tersedia.
- **Kanji N5:** 103 entri dalam delapan kelompok. **N4:** 166 entri dalam sebelas kelompok.
- **Kotoba N5–N1:** daftar kosakata dengan bagian yang dapat dibuka/tutup.
- Flashcard, agenda, rekap aktivitas, dan pencatatan progres.
- Cerita dengan furigana, terjemahan Indonesia, ilustrasi, dan audio perangkat.

Referensi level lanjutan berisi pilihan entri; kelengkapan contoh berbeda menurut entri.

## Mode Berpetualang — Petualangan Nao

Buka **Bahasa Jepang → Mode Berpetualang**. Mode ini terpisah dari katalog **Cerita** dan serial Nao yang sudah ada.

### Dua cerita

| Cerita | Judul | Chapter | Ragam bahasa |
| --- | --- | ---: | --- |
| 1 | Kota Baru, Teman Baru | 12 | Sopan/formal, terutama bentuk です・ます. |
| 2 | Janji di Bawah Lampion | 12 | Kasual antar teman, dengan contoh padanan bentuk sopan pada penjelasan. |
| **Total** | | **24** | **240 giliran dialog dengan terjemahan Indonesia.** |

Cerita pertama mengikuti Nao berkenalan, mengenal rumah dan lingkungan, serta berbelanja. Cerita kedua melanjutkan pertemanan Nao melalui persiapan festival dan perjalanan ke bukit. Bentuk kasual dipakai dalam hubungan pertemanan; penjelasan mengingatkan penggunaan bentuk sopan kepada orang yang belum dekat atau dalam situasi pelayanan.

Setiap cerita mempunyai tiga wilayah, masing-masing berisi empat chapter. Nomor chapter ditampilkan dari 01–12 pada masing-masing cerita.

### Alur bermain

1. Pilih cerita, wilayah, dan chapter pada peta.
2. Pilih **Mulai chapter** untuk mengikuti percakapan.
3. Gunakan **Lanjut**, **Sebelumnya**, atau **Dengarkan** pada dialog. Klik teks atau tekan Lanjut saat teks masih muncul untuk menampilkan seluruh kalimat terlebih dahulu.
4. Setelah percakapan, kerjakan paket soal campuran.
5. Periksa jawaban dan pembahasannya, kemudian lihat hasil akhir.
6. Ulangi jawaban keliru/kosong atau lanjutkan ke chapter berikutnya.

Chapter dapat dipilih melalui peta. Urutan disarankan untuk mengikuti alur, bukan sebagai kunci pembukaan chapter.

### Posisi, pose, dan gerakan karakter

- Dialog mendukung dua atau tiga karakter, dengan satu tokoh aktif berbicara.
- Saat Nao dan Haru datang bersama, keduanya berada pada sisi yang sama; tokoh ketiga berada di seberang.
- Arah hadap pendengar mengikuti posisi pembicara. Giliran bicara dan label nama mengikuti data tokoh pada setiap adegan.
- Pose menyapa, bertanya, menjelaskan, serius, dan menyimak dipilih berdasarkan dialog serta status pembicara.
- Perubahan pose memakai crossfade sekitar **1,4 detik**; latar memiliki gerakan kamera perlahan sekitar **8,5 detik**.
- Kotak dialog tetap di tengah bawah. Petunjuk Nao menggunakan jendela besar di tengah layar.
- Pergantian soal, pemilihan jawaban, dan tombol navigasi soal **tidak menggunakan transisi masuk/fade**.

Efek bergaya Morph merupakan perpaduan crossfade dan transformasi lapisan gambar. Ini bukan perubahan bentuk 3D atau animasi wajah berbasis rig. Preferensi reduced motion perangkat mengurangi gerakan.

### Kanji dan furigana

Dialog cerita menampilkan kanji dasar N5 yang sudah dipetakan beserta bacaannya. Tombol **Furigana ON/OFF** di bagian atas mengatur tampil/sembunyinya furigana dialog dan pilihannya disimpan di browser.

Fitur ini khusus dialog cerita. Teks soal tetap mengikuti bank soal tanpa penambahan furigana otomatis. Pemetaan bacaan menggunakan kamus lokal dalam kode, bukan analisis bahasa Jepang otomatis untuk semua kata.

### Audio dan log percakapan

- Setiap dialog diputar otomatis saat adegan dimulai. Tombol **Dengarkan** memutar ulang ucapan.
- Haru memakai profil suara laki-laki. Nao, Shiori, Akari, dan pemilik toko roti memakai profil suara perempuan.
- Tombol **Suara** menyediakan pemilihan serta uji suara Jepang yang tersedia pada perangkat.
- Pemilihan otomatis mengenali sejumlah nama suara. Jika suara sesuai profil belum tersedia, aplikasi memakai suara Jepang yang tersedia sebagai pengganti; gender suara tidak dijamin sama pada semua perangkat.
- **Log percakapan** di kanan atas menampilkan dialog chapter yang sudah dibuka, terjemahan, dan tombol audio ulang. Dialog yang belum dibuka tidak ditampilkan.
- Listening diputar otomatis saat soal baru dimulai. Pilihan **Normal 1×** dan **Pelan 0,72×** tersedia.
- Percakapan listening dua tokoh diputar berurutan dengan profil suara masing-masing.
- Memilih atau memeriksa jawaban tidak memutar ulang audio secara otomatis.

### Paket soal acak

Pilih **Paket baru: 5 soal / 10 soal** pada panel chapter. Paket awal menggunakan lima soal.

| Jenis | Fokus |
| --- | --- |
| Kosakata & kanji | Arti dan bacaan kata. |
| Memahami dialog | Urutan makna percakapan. |
| Menyimak | Memahami percakapan melalui audio. |
| Melengkapi kalimat | Partikel, bentuk kalimat, atau pemilihan ungkapan sesuai konteks. |

Keempat jenis dicampur dan urutannya diacak. Paket lima soal membatasi satu nomor sumber untuk satu soal. Paket sepuluh soal membatasi kemunculan nomor sumber dan menghindari pasangan bacaan/listening dari nomor sumber yang sama. Pengacakan mengurangi pengulangan, tetapi bukan pembuat soal baru tanpa batas.

Paket disimpan bersama progres, sehingga tidak berubah saat memilih jawaban, berpindah soal, atau memuat ulang halaman pada browser/alamat yang sama. **Paket baru** mengarsipkan jawaban paket sebelumnya dan membuat pilihan soal baru.

Target tuntas adalah menjawab seluruh paket dan mencapai **minimal 80% benar secara keseluruhan**: empat dari lima soal atau delapan dari sepuluh soal. Rincian hasil per jenis tetap ditampilkan untuk membantu pengulangan.

### Progres dan perubahan versi

Mode ini menggunakan kunci localStorage `tadicoba-nao-adventure-n5-v1`. Data mencakup jawaban, urutan paket, riwayat, chapter tuntas, dialog yang telah dibuka, serta pengaturan suara dan furigana.

Perombakan dua cerita menggunakan `storyVersion: 3`. Progres versi sebelumnya disimpan sebagai arsip `previousStoryMode`; penilaian cerita baru dimulai terpisah karena dialog serta ID soal berubah. Arsip ikut dalam JSON ekspor, tetapi belum mempunyai halaman penampil khusus. Impor langsung jawaban dari versi cerita lama ditolak agar indeks jawabannya tidak salah diterapkan pada soal baru.

Gunakan **Ekspor progres / Impor progres** di bagian bawah Mode Berpetualang. Cadangan ini khusus mode tersebut dan bukan cadangan seluruh data Jepang/Inggris.

## Print / PDF

- **Dasar Jepang:** tombol Print/PDF dan lembar kana **03 — Focus & Stack**. Hiragana dan katakana masing-masing disusun satu lembar, dengan border Tadicoba tetap dipertahankan.
- **Kanji N5/N4:** pilihan N5, N4, atau keduanya; pengelompokan, bacaan, dan arti.
- Layout ringkas kanji: portrait **13 — Dictionary Grid** tiga kolom; landscape **19 — Reading Ledger** empat kolom.
- Tersedia alur cetak materi dan kotoba sesuai menu. Materi harian mempertahankan alur cetak sebelumnya.

Cocokkan orientasi aplikasi dengan dialog cetak browser. Nonaktifkan header/footer browser dan periksa pratinjau sebelum mencetak. Hasil mengikuti ukuran kertas, margin, skala, dan area cetak printer; satu halaman pada semua ukuran kertas/printer tidak dapat dijamin tanpa pemeriksaan pratinjau.

## Latihan mikrofon

Audio contoh memakai `speechSynthesis`. Latihan berbicara memakai `SpeechRecognition` atau `webkitSpeechRecognition` jika didukung browser.

Penanda hijau/merah menunjukkan kecocokan **transkrip** dengan target, bukan penilaian fonetik atau aksen secara terperinci. Pengenalan suara dapat keliru. Hasil mikrofon belum menjadi riwayat progres permanen.

Gunakan HTTPS atau localhost, izinkan mikrofon, dan periksa suara bahasa target pada perangkat. Layanan pengenalan/sintesis suara tertentu dapat membutuhkan internet serta memproses audio melalui layanan browser.

## Menjalankan proyek

Versi utama berupa **HTML mandiri**. HTML memuat kode, materi, dan banyak aset tertanam; tidak memerlukan npm atau proses build untuk dipakai. Beberapa komponen pendukung dimuat dari CDN, sehingga seluruh fitur tidak dijamin tersedia tanpa internet.

Simpan HTML terbaru—yang mungkin bernama `index(1).html` saat diunduh—sebagai **index.html**. Letakkan README.md di folder yang sama. Ukuran HTML saat dokumentasi ini dibuat sekitar **66,6 MB / 63,5 MiB**.

Jalankan server lokal dari folder tersebut:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Pada Windows, gunakan `py` jika `python` tidak tersedia. Buka [localhost:8000](http://localhost:8000).

HTML tetap menjadi file utama untuk pembaruan berikutnya. Jika memakai salinan source code terpisah dari versi terdahulu, jangan menganggapnya otomatis sudah memuat revisi HTML terbaru.

## Publikasi GitHub Pages

1. Ekspor progres yang penting.
2. Ubah nama HTML unduhan menjadi **index.html**.
3. Ganti file utama pada folder sumber GitHub Pages repository.
4. Unggah **README.md** sebagai dokumentasi proyek.
5. Pastikan sumber Pages mengarah ke branch dan folder yang memuat index.html.
6. Tunggu deployment selesai, lalu buka website dan uji tombol pilihan bahasa, gambar, serta Mode Berpetualang.
7. Jika versi lama masih terlihat, coba muat ulang tanpa cache dengan Ctrl + F5.

HTML harus diunggah utuh. Jangan menyalin hanya potongan kode atau meninggalkan penanda konflik merge. Unggahan README sendiri tidak memperbarui aplikasi.

## Penyimpanan dan cadangan

Progres disimpan pada **localStorage**, terpisah menurut browser, profil, perangkat, dan origin/alamat situs. Jepang, Inggris per level, serta Mode Berpetualang mempunyai pengelolaan data masing-masing.

- Belum ada login atau sinkronisasi progres melalui server.
- Menghapus data situs dapat menghapus progres.
- Mengunduh HTML tidak memindahkan progres ke perangkat lain.
- Cadangan Inggris dipulihkan pada level yang sesuai.
- Cadangkan dari fitur terkait sebelum berpindah perangkat atau mengganti alamat situs.

## Pengembangan dan pemeriksaan

Komponen utama: HTML, CSS, JavaScript, SVG/Canvas sesuai fitur, Web Animations API, localStorage, sintesis suara, dan pengenalan suara browser.

Mode Berpetualang menggunakan `adventureData` untuk cerita/soal, `adventureVisualCSS` untuk tampilan, serta Shadow DOM agar gaya dashboard tidak mengganggu antarmuka mode ini. Setiap adegan menetapkan `speakerId`; peserta chapter dan posisi karakter menentukan arah hadap serta profil suaranya.

Saat mengubah data, jaga konsistensi tokoh, jumlah bab, terjemahan, kunci jawaban, audio, dan ID soal. Perubahan bank soal memerlukan migrasi/arsip; jangan menerapkan indeks jawaban lama pada pilihan baru. Hindari penggantian global tag HTML karena template cetak dan antarmuka juga ditulis dalam string JavaScript.

Pemeriksaan versi terbaru mencakup parsing JavaScript, 240 giliran dialog, arah hadap dua/tiga tokoh, kelompok Nao–Haru, kesesuaian label pembicara, pergantian profil suara, cadangan lama, serta 2.400 percobaan pembentukan paket acak. Pengujian fungsi DOM memakai pengganti API suara dan aset ringan; pengujian ini tidak membuktikan kualitas suara asli atau ketepatan visual pada browser pengguna. Tampilan akhir, layanan mikrofon, dan cetak fisik tetap perlu diuji pada perangkat nyata.
